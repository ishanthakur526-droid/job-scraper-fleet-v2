# Example Outputs

These files show the shape of the workflow outputs without committing live run data, logs, or local history.

- `sample_data_bi_roles_today.csv`: sample current-match CSV.
- `sample_new_only_data_bi_roles_today.csv`: sample new-only CSV.
- `sample_daily_summary_latest.md`: sample run summary.
- `sample_source_health_latest.csv`: sample source-health report.

Real outputs are generated under `outputs/` and are intentionally ignored by Git.
